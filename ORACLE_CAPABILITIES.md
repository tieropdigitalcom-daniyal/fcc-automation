# Oracle capability register

Documentation checked against Oracle's public reference on 12 November 2026. All live contracts remain unverified for the customer's tenant.

- Application discovery uses GET /HyperionPlanning/rest/v3/applications. The configured application must appear in items. Service Administrator is documented. [Oracle applications](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/get_applications.html)
- Export uses POST /HyperionPlanning/rest/v3/applications/{application}/jobs with jobType EXPORT_DATA, approved jobName and parameters.exportFileName. Service Administrator is required. The adapter requires an explicit verified TEST capability. [Oracle export data](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/export_data.html)
- Polling uses GET on jobs/{jobId}. Only numeric status 0 is successful. -1 is pending, and all other documented statuses fail the success gate. Both jobId and jobID are accepted because Oracle's table and example differ. [Oracle job status](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/retrieve_job_status.html)
- File inventory uses GET /interop/rest/v2/files/list. status 0 and an items array are required. External files include size and modification time. [Oracle file list](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/list_files_v2.html)
- File downloads use GET /interop/rest/11.1.2.3.600/applicationsnapshots/{encoded filename}/contents. JSON is an error even with HTTP 200. The application uses a 20 MB limit. Oracle documents 1 GB per request and no range/chunk contract here. [Oracle download](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/download.html)
- OAuth requires user context. The adapter accepts a runtime token provider, reads a rotated environment token on each request, and blocks expired tokens. Enterprise refresh and secure token rotation must be provided by the approved identity/secret service. [Oracle OAuth](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/authentication_oath.html)
- EPM Automate exportData and downloadFile use a configured executable, explicit arguments and an externally established encrypted OAuth session. Runtime installation and tenant execution remain unverified. [Oracle exportData](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cepma/epm_auto_export_data.html)
- Journal inventory uses GET /HyperionPlanning/rest/v3/applications/{application}/journals with scenario, year and period filters. The adapter validates pagination, totals, duplicates and independently supplied expected labels. Inventory is not a substitute for journal line evidence. [Oracle journal inventory](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/fccs_retrieve_journals.html)
- Journal export, intercompany report generation, raw tenant-specific export format parsing and runIntegration are unavailable in the runtime UI until their tenant capabilities and formats are verified. The generic CSV contract supports independently prepared journal lines and derived evidence. Oracle warns that denied journal members can appear as blank data. [Oracle journal export](https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/fccs_export_consolidation_journals.html)

An application command allowlist limits behavior, while Oracle's export role itself grants broader privileges. Provision and review the dedicated integration identity accordingly. No live Oracle call was executed during development.
